Join a game

Scan the host's QR code, or type the game code shown on the host phone.

Make the cards

Match each song to Spotify, then print. A song only counts when both the title and the artist match; songs that aren't on Spotify are skipped automatically. Orange ones matched on a slightly different title, so tap to listen if you want to check. Print double sided, flip on the long edge, and cut along the dashed lines. Matching all songs takes a few minutes, so keep the screen on.

Export song links

Saves every Spotify link on this phone, including fixes, to a small file. Send it to Mimo so the links can be built into the app for every phone.
